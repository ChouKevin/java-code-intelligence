# Java Code Intelligence — Source MCP

A source-first service for retrieving traceable evidence from an approved Git repository at an **exact commit**. Java 21 and three modules remain: `semantic-indexer` privately fetches Git and publishes immutable tracked source; `semantic-query` reads only published source through HTTP/MCP and real ripgrep; `semantic-model` contains JDK-only source contracts. Neither service runs an LLM, parser, JDT LS, MongoDB, target-repository build, or business inference. Semantic indexing and review tools are not part of this release (`semanticStatus: NOT_READY`).

## First use

Follow [Source MCP operations](docs/operations/source-mcp.md) to bootstrap a **new** service-owned local POSIX `/data` mount, inject separate secrets, configure approved repository IDs/URLs/default branches on Indexer and an explicit Query repository allowlist, then start both applications. Query mounts **only** `/data/source-published` read-only; Indexer owns the full `/data` parent. Startup registers sanitized descriptors; it does **not** fetch or prepare source. Keep the Indexer admin service private behind controlled TLS/ingress; expose Query read endpoints only to authorized clients.

Repository IDs are durably bound to their approved Git origin in both storage
namespaces. Repointing an existing ID or adopting populated unbound pre-release
storage fails closed; see [origin identity and rebuild rules](docs/operations/source-mcp.md#repository-origin-and-storage-identity).

Save a canonical lowercase UUID `requestId` durably **before** calling Indexer `prepare_source` (`POST /index/repositories/{repositoryId}/source` or private `/mcp`); optional `revision` must be a full lowercase 40-character SHA-1 commit. Get the original job by **either** `jobId` or `requestId` at `GET /index/repositories/{repositoryId}/jobs`. If the acceptance response is lost, look up the **original** request ID; do not resubmit or auto-retry an unknown outcome. Once COMPLETE, discover with `get_context`, copy the returned `{repositoryId, revision}` and retain it for every navigation call. Revision A remains readable after B is published. See [agent acceptance](docs/operations/mcp-agent-acceptance.md).

## Interfaces

Every HTTP and `/mcp` call requires `X-Api-Token`: `SEMANTIC_INDEXER_ADMIN_TOKEN` for private preparation, `SEMANTIC_QUERY_API_TOKEN` for reading. HTTP and MCP share input validation, results and safe errors.

Query MCP uses an initialized Streamable HTTP session per client; retain the
server-issued session ID for calls and cancellation, then close the session.
See the [MCP session lifecycle](docs/operations/source-mcp.md#mcp-session-lifecycle).

| Indexer MCP | Private HTTP |
| --- | --- |
| `prepare_source` | `POST /index/repositories/{repositoryId}/source` |
| `get_job` | `GET /index/repositories/{repositoryId}/jobs?requestId=…` or `?jobId=…` |

| Query MCP | Read HTTP |
| --- | --- |
| `list_repositories` | `GET /api/v1/repositories` |
| `get_context` | `POST /api/v1/context` |
| `list_files` | `POST /api/v1/files` |
| `search_text` | `POST /api/v1/search-text` |
| `read_source` | `POST /api/v1/source` |

`get_context` takes top-level `repositoryId` and optional exact `revision`; navigation uses nested `context` containing **only** `repositoryId` and `revision`. No old CURRENT/REVIEW/fact/generation/branch selector or legacy tool/route alias is supported. A registered but unprepared repository has no readable context. An optional externally reviewed [project guide](docs/operations/repository-context-prompt.md) is a `NOT_VERIFIED` navigation hint, never a business fact or preparation gate.

## Development and evidence

| Responsibility | Module |
| --- | --- |
| Git repository registry, private durable jobs, exact-commit export, atomic publication | `semantic-indexer/` |
| Published-only admission, bounded filesystem/ripgrep reads, HTTP/MCP and read token | `semantic-query/` |
| Source identity, manifest/state and framework-neutral requests/results | `semantic-model/` |
| Video source corpus; order/payment guide cases generated by the journey | `semantic-indexer/fixtures/uat/` |

Keep Query independent from Indexer implementation, JGit, private Git credentials and mutation; keep Model independent from frameworks. See [AGENTS.md](AGENTS.md) for coding boundaries and [testing](docs/operations/testing.md) for current commands and observed limitations. The source journey uses real Git/ripgrep and separate processes; passing it does not prove a particular external model, private repository, remote TLS deployment or business conclusion. Existing service data was **not** cleared for this cutover. Old Mongo/JDT clients and persisted contracts have no migration/shim in this release; the [operations guide](docs/operations/source-mcp.md#release-and-recovery) describes rebuild and rollback.

Use `bash scripts/verification-scope.sh --base <commit> --head <commit>` to select
final coverage (`--full` for shared/uncertain scope). During intermediate tasks,
run only focused native checks and keep commits local: no CI or image builds.
Complete the whole feature and local review before an authorized ready PR/final
dispatch; CI has no push trigger. Images belong on isolated final-acceptance CI,
not the default workstation loop. See [prerequisites, focused commands and
resource/data safeguards](docs/operations/testing.md). Local PostgreSQL and its
Docker engine/data remain untouched; they are not Source-first dependencies.
